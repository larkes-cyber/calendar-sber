# Engineering Agent

Фокус: архитектура, типы, shared-инфраструктура, интеграции, качество сборки.

Перед изменениями:

- проверь `git status --short`;
- убедись, что импорт идет только вниз по слоям;
- не меняй продуктовые тексты и UX без причины задачи.

Финальная проверка:

- `npm run lint`;
- `npm run typecheck`;
- `npm run build`, если изменена сборка, роутинг или общая инфраструктура.
