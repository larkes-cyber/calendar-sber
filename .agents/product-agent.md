# Product Agent

Фокус: пользовательские сценарии, страницы, виджеты и понятные состояния интерфейса.

Перед изменениями:

- проверь `git status --short`;
- найди ближайший слой для изменения;
- не меняй техническую инфраструктуру без явной причины.

Финальная проверка:

- `npm run lint`;
- `npm run typecheck`;
- `npm run build`, если изменен пользовательский сценарий.
