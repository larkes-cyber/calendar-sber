# Calendar Sber

React веб-приложение на Vite, TypeScript, Feature-Sliced Design и FullCalendar.

## Быстрый старт

```bash
npm install
npm run dev
```

## Скрипты

- `npm run dev` - локальный сервер разработки.
- `npm run build` - проверка типов и production-сборка.
- `npm run lint` - статический анализ.
- `npm run format` - форматирование проекта.
- `npm run typecheck` - только TypeScript-проверка.

## Архитектура

Проект разделен по слоям:

- `app` - провайдеры приложения, роутинг, глобальные стили.
- `pages` - страницы маршрутов.
- `widgets` - крупные блоки интерфейса, собирающие фичи и сущности.
- `features` - пользовательские сценарии.
- `entities` - бизнес-сущности и их UI/API/model.
- `shared` - переиспользуемая инфраструктура, UI-kit, utils, config.

Правило зависимостей: слой может импортировать только нижележащие слои. Например, `features` может импортировать `entities` и `shared`, но не `widgets` или `pages`.

## Референс Nextcloud Calendar

В проект перенесены архитектурные идеи из `nextcloud/calendar`: FullCalendar как ядро отображения, URL-driven view/date, разделение календарей и событий, сайдбар источников и панель деталей события. Подробности: `docs/nextcloud-calendar-analysis.md`.

## Работа в команде с AI-агентами

- Один агент ведет продуктовую/UX часть: страницы, тексты, состояние пользовательских сценариев.
- Второй агент ведет техническую часть: архитектура, shared-инфраструктура, типы, проверки.
- Перед изменениями агент смотрит `git status`, не трогает чужие незакоммиченные файлы и описывает затронутые слои.
- Любая задача заканчивается `npm run lint` и `npm run typecheck`; для пользовательских сценариев дополнительно `npm run build`.
